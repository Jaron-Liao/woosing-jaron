## 二、关键前提：两条域名路线，只有一条能保住微信登录

OAuth 中继的硬规则是：`callback_url` 必须是**已注册在某个已发布应用上的域名**。所以：

| 路线 | 能绑定 | 微信扫码登录 | 结论 |
|---|---|---|---|
| A. 应用管理页「自定义域名」 | 设置 → 数据管理 → 应用 → 选 CodeVerse → 自定义域名 | **大概率可用**（域名挂在应用上，符合中继要求） | 走这条 |
| B. EdgeOne Pages 自定义域名 | 腾讯云 EdgeOne 控制台 → 域名管理 | **大概率 400**（域名不属于"已发布应用"） | 只适合纯静态展示站 |

> 我没有替你猜：**你绑完一条，我立刻用你的域名打一次中继**，几秒就知道放不放行（命令见第四节）。

## 三、绑定步骤（路线 A）

1. 先在腾讯云/阿里云注册域名，完成**实名认证**（个人身份证，1–2 个工作日）。
2. 若要走中国大陆加速/备案：腾讯云「备案」入口提交，通常 7–20 个工作日。**不备案也能先绑，只是没有国内加速节点。**
3. 打开 WorkBuddy：**设置 → 数据管理 → 应用 → CodeVerse 数学代码工作台 → 自定义域名**。
4. 输入域名（建议先绑 `www.子域`，如 `www.codeverse.work`），平台会给一条 **CNAME** 目标，形如 `xxx.eo.dnse.com`。
5. 去域名解析控制台加记录：

```
类型：CNAME
主机记录：www          # 绑裸域就填 @
记录值：<平台给的 CNAME 目标>
TTL：600
```

> 不要用「线路/地域」解析，这是证书验证失败最常见的原因——CA 是从境外验证的。

6. 回平台点「验证」→ 状态「部署中」→ 申请免费证书（TrustAsia / Let's Encrypt）→ 约 5 分钟「已生效」。
7. 检查 CAA 记录：如果有，必须放行 `letsencrypt.org` 与 `digicert.com`，否则签发被拒。

## 四、绑定后我这边怎么验证（你只要把域名发我）

```bash
# 用你的域名当 callback_url 打一次中继：302 = 放行，400 = 微信登录在该域名不可用
node -e "fetch('https://www.workbuddy.cn/v2/as/genie-baas/oauth/authorize?provider=wechat&callback_url='+encodeURIComponent('https://你的域名/'),{redirect:'manual'}).then(r=>console.log(r.status, r.headers.get('location')||''))"
```

- **302 → open.weixin.qq.com/connect/qrconnect**：完美，我把 `PUBLISHED_ORIGIN` 换成新域名即可，微信登录跟着走。
- **400 not a registered domain**：说明该域名没挂在应用上，微信登录必须留在 `codeverse-workbench.app.workbuddy.host`；新域名只能做落地页，我给它加「跳转到发布域名登录」的自动引导。

## 五、当前的兜底行为（已上线）

- 任何时候打开非发布域名，登录页顶部显示橙色「当前不是发布地址」，微信按钮变「在发布地址打开微信登录」，一点就带 sharecode 跳过去并自动出二维码。
- 所以即便域名暂时没绑好，**用户也不会再撞到那张「当前地址暂不支持此登录方式」的死胡同页**。
